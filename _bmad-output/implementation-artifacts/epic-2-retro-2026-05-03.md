## What Went Well

1. **Story 2.0 cleanup pattern fully closed.** Story 2.0 triage table was honored end-to-end: the reassigned-to-Story-2.10 `RegisterIfMissing` helper was actually shipped in Story 2.10, and Story 2.5 planted it. The mandatory Epic-N retro gate works when the lead reads it. (See Rule 9 below for the failure mode of the same pattern.)

2. **Auto-sync workflow held across 13 stories.** Zero `iris_doc_load` round-trips for production class edits. Saved measurable token spend per story. Codified in Epic 1 (`fe6277c`) and held through Epic 2 with no regressions.

3. **Adapter pattern shipped clean.** Story 2.8's canonical-Anthropic-shape decision plus Story 2.9's concrete OpenAI implementation validated the FR28 "5th-provider extensibility" contract. Stories 5.1/5.2/5.3 (Anthropic/Gemini/OpenAICompat concretes) inherit a working pattern.

4. **L2 read-only enforcement empirically verified.** `test_write_tool` (MutatesState=1) blocked at the `Tool.Registry.Dispatch` boundary: `{isError:1, content:[..."Tool blocked by read-only policy"]}`. The structural enforcement of NFR-S1 Layer 2 works.

5. **Audit ledger 100% completeness invariant proven.** Live OpenAI multi-tool turn against Ens session 3: 2 LlmCall + 2 ToolCall rows, both FK-linked to Chat.History row, both with accurate LatencyMs. The NFR-S4 contract holds in production.

6. **Lock-release discipline held in AgentLoop.** All 9 RunTurn code paths verified to release the `%OpenId(id, 4)` exclusive lock. The most subtle cross-story invariant (Chat.History from Story 2.6 + AgentLoop from Story 2.12) survived the retro empirical battery.

7. **Discipline rules from Epic 1 retro actually held (mostly).** Rules 1, 2, 3, 5 all enforced naturally across 13 stories. The pattern of codifying retro lessons as `.claude/rules/*.md` files works.

## What Didn't Go As Well

1. **The user-led empirical battery caught 5 shipped bugs.** Same pattern as Epic 1 retro. Five real, shipped defects in `main` after 13 stories of dev/reviewer cycles + a "complete" SmokeTest:
   - **HIGH** — MessageAdapter `tool_result` translation broken for OpenAI (multi-turn HTTP 400). Reviewer literally predicted this in Story 2.8's deferred-work entry.
   - **MEDIUM** — `DefaultSSL` SSL config undocumented operator prereq. Story 2.9 spec said "operator prereq, see README"; README never said how.
   - **MEDIUM** — Test isolation: `^SessionAgent.Config.AgentD` wiped mid-suite by ConfigAgentTest, breaking AgentLoopTest/SmokeTest in suite order.
   - **LOW** — Test stub tools advertised by `Tool.Registry.ListTools` to production callers.
   - **LOW (was by-design)** — Blocked / unknown tool dispatches skipped audit emit (NFR-S4 100% completeness gap).

2. **Mock smoke test was theater.** `Test.SmokeTest.cls` (Story 2.12) used a mock provider returning canned responses in the canonical wire shape we already knew worked. It passed. Real OpenAI failed turn 2 immediately. Mocks-as-smoke-tests are a structural anti-pattern when the wire format is the thing being tested.

3. **Predicted-bug deferral pattern.** Story 2.8's code reviewer wrote a deferred-work entry naming the file, line range, missing test, AND reassigned ownership to Story 2.9. Story 2.9's code reviewer (cr-2-9, fresh context) didn't read Story 2.8's deferred-work, didn't add the test. Bug shipped. The deferred-work mechanism became write-only.

4. **Stale model-default went unchallenged for 13 stories.** Story 2.4 set `OpenAI: gpt-4o` as the canonical default. Architecture.md OD4 row literally said *"verify current model name before each release tag"*. No verification ever happened. User caught it in retro: gpt-4o is 6.25× more expensive than gpt-4.1-mini for the same tool-calling reliability and 8× smaller context window. We rebuilt 12 files of canonical references after the fact.

5. **Operator credential setup was treated as retro-time work, not sprint-planning work.** API key + DefaultSSL + Enabled=1 toggle should have been requested at Epic 2 sprint planning. Without them, Story 2.12 SmokeTest had to be a mock; with them at planning time, it could have been a real live test that would have caught all 5 bugs at story-author time.

6. **`iris_execute_tests` package-runner truncation became the cycle's tax.** Stories 2.4 through 2.12 each independently ran into the per-class wall-clock cap, each independently worked around it via per-class sweeps, each documented it. Tooling friction we accepted instead of escalating. Worth flagging in deferred-work for an MCP-side improvement request.
