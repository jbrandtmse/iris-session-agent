## What went well

1. **The empirical gate stack caught everything.** 2 HIGH (comment-prefix EXPLAIN bypass; override-restore hygiene) + ~31 MED found and fixed in-cycle; 0 escaped to the branch tip. Smoke gates caught 2 live defects automated tiers passed (disabled agent row; PATH env-var pollution); the walkthrough caught 1 more (bare-host `/v1`) and fixed it same-day.
2. **Carry-forward bindings are now load-bearing.** Epic 13 AI-2/AI-3 closed via verbatim spec callouts — zero raw `isError` envelopes and zero EXPECTEDTOOLCOUNT misses across 4 tool stories (vs. ~1 reviewer catch per story in Epic 13). Cleanest previous-retro follow-through of any epic (4/4 bindable items closed, 2 re-deferrals intentional).
3. **Task 0 probes overrode documentation twice, correctly.** EXPLAIN prepares as `statementType=1` (docs say 79) → validator-level allowance design; `UPPER()` on `%Dictionary.parent` defeated the index (10.9s→2.0s dispatch) → documented exception. Both would have shipped wrong without probe-first.
4. **Security held under adversarial pressure.** The read-only covenant survived a 3-layer review + 11-test adversarial battery + live write-proofs; the one real bypass found (comment-prefixed EXPLAIN) was depth-defended (it mutated nothing) and fixed.

## What didn't go well

1. **Ambient test pollution of live operator config — 4+ incidents (lead-selected top concern).** Interrupted/killed test runs cannot execute their capture/restore teardowns: `Enabled=0` (14.5 smoke catch), `EnvVarName=PATH` (battery catch), stale Epic 13 count locks (14.0 pre-state), run-203 mid-dev sweep artifacts (14.4). Every incident was caught by a gate; each cost an investigation cycle. The restore-pattern code is correct — the failure mode is structural (process death). **→ AI-1.**
2. **Subagent infrastructure friction recurred all epic:** `iris_execute_tests` envelope truncation (every run), auto-sync not firing for tool-driven writes (iris_doc_load fallback needed), PostToolUse formatter reverting edits (5+ catches), one dev socket-drop requiring a continuation agent, stale Atelier worker code. All have codified workarounds; the per-incident tax remains. **→ watch-item.**
3. **One unreproduced transient:** OpenAI HTTP 431 on a single VisualTrace first-turn; instrumentation showed normal header sizes on the immediately-following identical turn. Documented, not root-caused.
